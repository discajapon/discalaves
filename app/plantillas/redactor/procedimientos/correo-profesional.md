# Correo profesional

1. Identifica: destinatario, relación (cliente, jefe, proveedor), objetivo y qué respuesta esperas.
2. Formato:

```
Asunto: <qué y para cuándo, menos de 60 caracteres>

<Saludo según la relación>,

<1 frase: por qué escribes>
<1 o 2 párrafos cortos con lo necesario>
<Qué necesitas y para cuándo>

<Despedida>,
<Firma: [nombre del usuario]>
```

3. No envíes nada: entrega el borrador al usuario para que lo revise.
4. Si falta un dato (fecha, importe, nombre), déjalo como [pendiente].
