# Corregir un texto

1. No cambies el sentido ni el tono del autor.
2. Corrige: ortografía, tildes, puntuación, concordancia y palabras repetidas.
3. Mejora la claridad solo donde una frase se entienda mal.
4. Entrega:
   - El texto corregido completo.
   - Debajo, una lista "Cambios principales" con los 3 a 8 cambios más importantes (antes → después).
