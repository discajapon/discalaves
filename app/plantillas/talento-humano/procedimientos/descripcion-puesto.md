# Descripción de puesto

1. Confirma: puesto, área, modalidad (presencial, remoto, híbrido), jornada y país.
2. Escribe en `personas/puesto-<nombre>.md`:

```
# <Puesto>
**Área:** ... · **Modalidad:** ... · **Jornada:** ...

## Para qué existe este puesto
2 frases.

## Responsabilidades
- 5 a 7 viñetas con verbos de acción.

## Requisitos
- Imprescindibles (máximo 5).
- Deseables.

## Qué ofrecemos
- [pendiente: lo completa el usuario]
```

3. Revisa que no haya requisitos discriminatorios ni lenguaje que excluya.
