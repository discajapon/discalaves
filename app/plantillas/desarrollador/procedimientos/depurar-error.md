---
descripcion: encontrar y arreglar un error a partir de un mensaje o comportamiento raro
---
# Depurar un error

1. Reproduce el error con terminal y copia el mensaje exacto.
2. Aísla: reduce el caso al mínimo que sigue fallando.
3. Formula una hipótesis de la causa y compruébala (un print, un comando) antes de cambiar código.
4. Arregla la causa, no el síntoma.
5. Vuelve a ejecutar el caso original y la prueba: muestra que ya no falla.
6. Responde con:

```
Causa: ...
Arreglo: ...
Comprobación: <comando y salida>
```
