# Revisar código

1. Lee el código completo y, si se puede, ejecútalo.
2. Busca, en este orden: errores (fallos, casos límite), seguridad (datos de entrada, contraseñas en el código), claridad (nombres, duplicación), rendimiento.
3. Entrega una lista numerada, de más grave a menos:

```
1. [error|seguridad|claridad|rendimiento] archivo:línea — qué pasa — cómo arreglarlo
```

4. No reescribas todo: propone cambios concretos y pequeños.
