# Crear un proyecto

1. Aclara qué debe hacer, con qué entrada y qué salida. Si falta, pregunta.
2. Crea `proyectos/<nombre>/` con:
   - el código,
   - `README.md` (qué hace, cómo se ejecuta, ejemplo),
   - una prueba mínima (un script o `test_*.py` que falle si el código se rompe).
3. Ejecuta la prueba con terminal y muestra la salida.
4. Si falla, corrige y vuelve a ejecutar hasta que pase.
5. Responde con: qué hiciste, cómo ejecutarlo y la salida de la prueba.
