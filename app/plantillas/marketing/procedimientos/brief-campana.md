# Brief de campaña

Escribe en `marketing/brief-<nombre>.md`:

```
# Brief: <campaña>
Objetivo (medible): ...
Público: ...
Mensaje principal (1 frase): ...
Mensajes de apoyo: 3 viñetas
Canales y por qué: ...
Calendario: fechas clave
Presupuesto: [lo decide el usuario]
Cómo sabremos si funcionó: 2 o 3 indicadores
Riesgos: ...
```

Si falta el objetivo o el público, pregúntalos antes de escribir.
