# Análisis de la competencia

1. Pide o busca 3 competidores directos.
2. Abre la web de cada uno y anota solo lo que se ve: propuesta de valor, precios (si son públicos), canales, tono.
3. Escribe en `marketing/competencia.md`:

```
| | Competidor A | Competidor B | Competidor C |
|---|---|---|---|
| Propuesta | | | |
| Precio | | | |
| Canales | | | |
| Tono | | | |

## Huecos que podríamos ocupar
- ...

## Fuentes
- dirección (fecha de consulta)
```

4. Lo que no esté publicado queda como "no público"; no lo supongas.
