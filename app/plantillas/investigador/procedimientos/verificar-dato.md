# Verificar un dato

1. Escribe la afirmación exacta que vas a comprobar.
2. Busca al menos 2 fuentes independientes (no una que copie a la otra). Da prioridad a la fuente original: organismo, estudio, documento oficial.
3. Anota la fecha de cada fuente: un dato viejo puede haber cambiado.
4. Responde con este formato:

```
Afirmación: ...
Veredicto: cierto / falso / parcialmente cierto / no se pudo comprobar
Por qué: 1 o 2 frases.
Fuentes:
- dirección (fecha) — qué dice
```

Si no encontraste 2 fuentes independientes, el veredicto es "no se pudo comprobar".
